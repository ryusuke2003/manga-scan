# Manga Scan の画質判断

このスキルは manga-scan の画像処理とレビュー体験に適用する。候補の採点値だけでなく、最終的にユーザーが読むページの状態で判断する。

## 第一優先：内容を読めること

- ページの本文・絵・端が見切れず、指や未補修領域で文字やコマが隠れず、ブレ・ピンぼけ・露出不足・強い反射で読みにくくならないことを先に確認する。
- 読める候補の中では、検出された指の面積、とくに本文上に残る面積をできるだけ小さくする。指面積だけを最小化して、ブレや欠けのある候補を選ばない。
- 元フレームと、切り出し・補修・補正後の最終ページを両方確認する。補修が不完全な場合や、検出値が小さくても指が文字に残る場合を見逃さない。
- 重複した見開きや後続フレームにも良い候補がないか確認する。手動で確定した選択は自動選択で上書きしない。

## 第二優先：読むときの見やすさ

- 第一優先を満たした候補の中で、背景の机の写り込み、ページの湾曲、遠近の歪み、傾き、照明ムラなどを減らす。
- 見た目を整える処理で本文や絵を切り落とさない。表紙や見開きも含め、外周と最終出力を確認する。

## 変更を検証するとき

- 候補選択の変更では「指が少なく鮮明」「指は少ないがブレる」「端が欠ける」「後から良い重複候補が出る」を、該当する処理経路で確認する。
- 補正や UI の変更では、実際の最終画像とレビュー画面で読める範囲を確認する。検出値や単体テストだけで品質を断定しない。
