# 制約・既知の限界

Manga Scan Localは、撮影動画からレビューしやすい候補を抽出し、
安全側にfallbackしながら補正することを目的としています。
元映像に存在しない情報を生成して復元するツールではありません。

## 主な制約

- 通常解析は10fps。欠落候補や問題候補の一部だけ自動high-fps fallbackで再確認する
- high-fpsでも十分な連続低motion区間を確認できない場合は自動復旧しない
- 手で常に隠れている領域は復元できない
- MediaPipeは指先だけの手や漫画に描かれた手を誤判定する可能性がある
- 射影変換は平面を仮定するため、背の強い湾曲は完全には補正できない
- 自動dewarpも完全な3D形状復元ではない
- HDR / Dolby Visionの色忠実度は未検証で、MVPは8bit出力
- ROI追従には1回の移動量と累積移動量の安全上限がある
- 大きな本の移動や追跡confidence不足ではtrusted ROIへfallbackする
- 元動画の画面外に出た絵は復元できない
- OCRを使わないため、印刷されたページ番号から欠落を推定しない
- 見開き処理中の中断・再開には対応するが、動き解析途中の内部状態は保存しない
- 動き解析中に停止した場合は、その解析を最初からやり直す
- 期待ページ数チェックはユーザー指定値と現在の有効ページ数の照合であり、OCRではない
- 「安全な改善候補」は既存の撮影候補だけを使い、自動採用しない

## 複数動画・外部画像

1冊を複数回に分けて撮影した場合は、
UIで動画を撮影順に追加して1本のタイムラインとして解析できます。

Review画面からPNG / JPEG / WebP画像を新規ページとして追加したり、
失敗した1ページだけ外部画像で差し替えたりできます。

PNG / JPEG / WebPだけで撮影した1冊は、
静止画フォルダからまとめて読み込めます。

## 実写での利用

実写漫画での精度や長時間4K動画の性能は、撮影条件によって変わります。
最初は数ページの短い動画で撮影条件を調整してください。

検証状況は [検証記録](validation.md) を参照してください。
